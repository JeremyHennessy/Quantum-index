# Researcher navigation and Explore home — 2026-09-29

Baseline main: `ca1a58bdbf7bc9237e79058215e4124bc25b29ce`.

This release adds a task-oriented Explore landing view without removing any existing scientific surface.

Explore provides direct entrances to:
- scientific Problems;
- theory/framework catalog;
- Formula Atlas;
- Evidence and constraints;
- reviewed recent developments ("What's New");
- historical origins/timeline;
- Compare;
- Research Questions;
- Learning Paths;
- My Research.

It also surfaces the latest four reviewed DevelopmentEvents and a sample of reviewed open ResearchQuestions.

The app now defaults to Explore when no explicit route is supplied. Existing deep links to map, timeline, catalog, formulas, Problems, Evidence, Questions, learning and workspace remain valid.

No theory, formula, relationship, Evidence, Problem, Question or DevelopmentEvent scientific content is changed.
