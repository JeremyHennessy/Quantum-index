# Curated Theory Passports — 2026-09-29

Baseline main: `cf04c66624ea6e1357ec9892a6e11d5ac4d76280`.

This release adds ten structured Theory Passports for high-value hub entries:
- Hawking radiation
- Quantum extremal surfaces / island formula
- Environment-induced decoherence
- GRW spontaneous-collapse theory
- Loop quantum gravity
- String theory
- Eigenstate thermalization hypothesis
- Many-body localization
- ΛCDM
- WIMP dark matter

Passports expose:
- linked scientific Problems;
- entity type and descriptive scientific status;
- core idea;
- fundamental objects / degrees of freedom;
- assumptions;
- mathematical structure and curated formulas;
- regime / limits;
- predictions / consequences;
- Evidence / constraints;
- known limitations;
- ResearchQuestions;
- recent DevelopmentEvents;
- source IDs and review date.

The Passports organize existing sourced content and do not replace the underlying literature. Missing experimental evidence is left explicit. In particular, Hawking radiation is not described as directly astrophysically detected, the Diósi–Penrose constraint is not treated as a GRW-specific exclusion, and the 2026 LZ candidate excess is not described as a dark-matter discovery.
