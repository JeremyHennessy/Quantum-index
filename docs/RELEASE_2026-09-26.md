## Verification and rollback

Run `npm ci`, `npm test`, and `npm run validate`. CI checks UI navigation against the actual application DOM and D3 implementation, chronology, formula associations and generated coverage.

Rollback uses a revert of the release merge commit. No database, dependency migration or hosting configuration change is required. New npm dependencies are development-only; the deployed static application keeps its existing CDN dependencies.
