# Inspectable research navigation

The Network view includes a directed-path form. Select two catalog entries and an edge limit, then submit with the button or keyboard. The resulting URL can be saved or shared. Search is catalog-wide, independent of graph display filters.

Only stored edges with nonempty resolving citations, high/medium curator confidence and non-editorial evidence type are eligible. Direction is never reversed, including for overlap edges. Breadth-first search returns one shortest eligible path, breaking ties deterministically rather than ranking scientific importance. Every selected edge exposes its stored type, scope, confidence, source bibliography and all recorded exact locators.

A path is not a logical proof, a causal chain, empirical confirmation or equivalence of the endpoints. “No documented directed path within N edges” describes the current catalog and bound, not scientific impossibility. Same endpoint returns zero edges and makes no relationship assertion. Missing citations stop the calculation rather than trigger an editorial fallback. The browser and `scripts/sourced-paths.mjs` CLI share the same pure engine in `sourced-paths.js`.

Coverage includes a catalog-entry selector. Its drill-down reports actual entry provenance, linked bibliography, formula review status/locator counts, representative-formula gaps, profile/Passport presence, associated Evidence and source-backed incident relationships. These are factual catalog inventories, not an aggregate validity score. Evidence association is not confirmation; absence of a catalog record is not absence of research.

The cosmology learning route is explicitly editorial. Its four study steps do not generate graph edges. Its transfer primer separates initial conditions, gauge/species-qualified linear evolution, projection and conditional inference. It reuses Planck/BK18/DESI Evidence and existing scientific Problems. No new transfer formula or empirical result is invented.

The foundational audit promotes fifteen existing formula metadata records after inspection of authoritative reference equations. It does not alter equations, identities or theory links. Original historical references remain provenance, not newly inspected originals. Unbounded-operator domain comments are conservative restrictions rather than an exhaustive theorem audit; this release does not prove the Born rule or claim a novel discovery. The exact source/audit receipts are in `research/FOUNDATION_SOURCE_AUDIT_2026-10-21.json`.

These tools do not write bookmarks, notes or reading markers. Existing learning-path progress continues to use the established local workspace format. No storage migration is required.
