# Exact plaquette multiplication on a three-square Wilson strip

November 27, 2026 UTC. This supplies the finite multiplication entries requested by the [residual budget](../three-square-residual-budget/README.md). It does not yet compute a trial eigenvector or certify the single-face transition at b=.01.

Use the earlier physical labels L,R,J,K,T,U, with L and R the length-three paths after bivalent vertices are composed. The physical Hilbert spaces and loop multiplications are unchanged by composition; the three independent temporal edge multipliers on each such path remain cubed in K. The four trivalent vertices are (L,J,T), (L,J,U), (R,K,T), (R,K,U), and the script records consistent orientations. We use the [spin-network construction](https://arxiv.org/abs/hep-lat/9906036) and the [standard 3j/Clebsch–Gordan relation](https://dlmf.nist.gov/34.3).

Each edge uses the orthonormal Haar matrix elements √(n+1) D^n. At a vertex place the unit real Wigner 3j tensor, converting an incoming leg into its dual using (−1)^((n−m)/2) and magnetic index −m (n and m are doubled integers). For each same-edge multiplication with incoming network labels n,l and output j, the product identity contributes two Clebsch–Gordan coefficients and the scalar √((n+1)(l+1)/(j+1)). Contract the magnetic indices at each vertex. The coefficient is a product of four finite vertex contractions and the six dimension factors; it does not require spatial quadrature. Triangle supports are generated before arithmetic. A simple loop’s normalized fundamental network equals the character up to phase and the code fixes that sign by checking its value is ±2 at identity. Multiplication uses half the signed network, not the full trace. The magnetic sums and square roots are evaluated exactly with SymPy.
